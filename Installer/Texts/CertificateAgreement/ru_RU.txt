СОГЛАШЕНИЕ О СЕРТИФИКАТЕ:
Bedrock Cosmos требует установки корневого сертификата Titanium Proxy при первом запуске прокси-системы. Сертификат Titanium Proxy позволяет нашему приложению считывать и изменять ответы API Minecraft для отображения наших пользовательских меню в игре.

НАСТОЯТЕЛЬНО РЕКОМЕНДУЕТСЯ не устанавливать корневые сертификаты из источников, которым вы не доверяете, поскольку они могут использоваться для фишинговых атак и кражи учетных данных. Bedrock Cosmos всегда будет оставаться программным обеспечением с открытым исходным кодом, чтобы пользователи могли напрямую видеть, как наш прокси обрабатывает данные в их системах.
